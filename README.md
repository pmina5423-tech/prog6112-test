# PROG6112_Test

This is my PROG6112 Test 1 project. It has two Java programs that run in the NetBeans console. The first one prints a report from a 2D array. The second one uses an interface, an abstract class and a subclass.

## Question 1

`ArrayReport.java` makes a 2D array and fills it with values. It prints the array by rows and then by columns. After that it works out the total of each row and column, and finds the highest and lowest value. Everything is printed in the console as a report.

## Question 2

I split this question into four files, one for each part:

- `[Interface].java` lists the methods that the classes must have.
- `[AbstractClass].java` has the variables, the constructor and the getters. It implements the interface.
- `[Subclass].java` extends the abstract class. It has its own constructor and its own version of the print method.
- `[MainApp].java` creates the objects and prints the output.

## How to run it

1. Open NetBeans, click File, then Open Project, and pick the `PROG6112_Test` folder.
2. For Question 1, right-click `ArrayReport.java` and click Run File.
3. For Question 2, right-click `[MainApp].java` and click Run File.
